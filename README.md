# Clean Academic Project Page Template

This directory contains a media-free version of the PhysReal project-page structure.

## Main files

- `index.html`: page structure and placeholder copy
- `static/css/index.css`: visual styling
- `static/js/index.js`: data-driven video grids, comparisons, and carousels
- `static/images/`: add project images here
- `static/videos/`: add project videos here

Update the configuration arrays at the top of `static/js/index.js` after adding media.
Retain the template attribution in the footer.
